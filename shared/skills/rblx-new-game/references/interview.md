# Project choices

Use inspection and existing answers to propose concrete defaults. Ask only for
choices needed by the scaffold; combine related missing choices when clear.

- Gameplay: repeated player action, reward/result, and continuation or restart.
- Places: named places; keep the multi-place layout for a single place too.
- Modules: detected Services/Controllers first, then gameplay additions, each
  assigned to shared scope or a named place. Apply the skill's naming rules.
- Assets: packages, services, controllers, and plugins independently; any subset,
  `all`, or `none`. Existing plugins retain support.
- Harness: whether to install rblx-harness. An explicit setup request supplies
  authorization; do not ask again. Permission-profile selection is separate.
