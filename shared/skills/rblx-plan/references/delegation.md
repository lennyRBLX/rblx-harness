# Delegated work

Use only when the user or project requests delegation.

- Research unresolved contracts with `researcher`; use `debugger` while a failure's
  cause is unknown. Keep straightforward implementation in the primary agent.
- After implementation or plan drafting, run `optimizer`, resolve its findings,
  then run `reviewer`. Source/plan assessment needs no capture.
- Pass exact owned paths, symbols, contracts, restrictions, valid evidence and open
  questions. For plans, review dependencies, authority, lifecycle and acceptance.
- For model-setting changes or comparisons, read [models.md](models.md).
