# Harness maintenance

This repository supplies Roblox skills, tools, and project setup. Edit canonical
files in `shared/`, `tools/`, `openai/`, `anthropic/`, and `templates/`; `.agents/`,
`.codex/`, and `.claude/` are generated by `python3 setup_project.py --harness`.

Use official Codex and Claude Code configuration and skill discovery. Keep project instructions
short and load task details through skill references. Preserve unrelated user
configuration during setup. Tool commands are listed by
`python3 tools/harness.py --help`.

Run `python3 tools/harness.py check harness --case MATCH` for affected behavior;
use the full suite for broad harness changes. Reuse valid results. Package source
is a supplied asset; a harness configuration change does not require a Studio run.
